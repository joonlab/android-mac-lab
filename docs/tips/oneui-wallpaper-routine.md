# 폴드8 배경: 접힘·펼침·회전마다 다른 그림 + 충전하면 바뀌는 잠금화면

폴드8에는 화면이 두 개(커버, 펼친 화면)이고, 펼친 화면은 돌리면 가로·세로 비율이 바뀝니다. 이 셋에 각각 다른 배경을 넣고, 충전기를 꽂으면 잠금화면이 영상으로 바뀌게 만든 방법입니다. 인터넷 쇼츠에서 본 꾸미기를 따라 하면서, 설정은 전부 맥에서 adb로 했습니다(루트 불필요).

> **English** — How I gave a Galaxy Z Fold8 three different wallpapers (cover, unfolded landscape, unfolded portrait) using one stacked collage image, widened a portrait video to 4:3 for the inner lock screen, and added a One UI "Modes and Routines" rule that swaps the lock screen to a video while charging. All done over adb with no root.

제가 실제로 쓴 그림은 만화 캐릭터라 저작권 때문에 여기 넣지 않았습니다. 방법만 적습니다.

## 결과

| 상태 | 홈 화면 | 잠금화면 | 충전 중 잠금화면 |
|---|---|---|---|
| 커버 | 그림 A (원본) | 영상 1 | 영상 2 |
| 펼침(가로) | 그림 B (가로 4:3판) | 영상 1 (4:3판) | 영상 2 (4:3판) |
| 펼침(세로) | 그림 B' (세로 3:4판) | 위와 같음 | 위와 같음 |

## 먼저 화면 비율부터 잽니다

`adb shell wm size` 로 두 화면의 실제 해상도를 확인합니다. 제 폴드8은 이랬습니다.

- 커버: 1248 × 1972 (약 0.633)
- 펼친 화면: 2448 × 1848 — **펼친 기본 방향이 가로로 넓은 4:3**입니다. 돌리면 1848 × 2448(3:4)

「펼친 화면은 세로」라고 가정하면 처음부터 틀립니다.

## 1. 원본 비율 맞추기

- 비율 차이가 1~2% 이내면 그대로 씁니다(제 커버용 그림은 0.625 대 0.633).
- 그보다 크게 다르면 **늘리지 말고**, 원본을 참고 이미지로 넣어 이미지 생성 모델로 목표 비율판을 다시 만듭니다. 프롬프트의 핵심은 「인물·자세·얼굴은 그대로, 주변만 넓힐 것」입니다. 세로판은 위쪽 1/4을 비워 두면 시계가 그림을 가리지 않습니다.
- 저는 3:4판과 4:3판 두 장을 만들었고, 이미지 네 장에 든 비용은 약 $0.39였습니다.

## 2. 가로·세로에 다른 배경 — 콜라주 한 장

One UI 배경 편집기는 사진 한 장을 받아 보이는 영역만 옮길 수 있습니다. 그래서 **세로판을 위에, 가로판을 아래에 폭을 맞춰 붙인 긴 그림 한 장**을 넣습니다.

```
폭 1848으로 통일:  세로판 1848 × 2453 (위)  +  가로판 1848 × 1392 (아래)  =  1848 × 3845
```

- 세로로 돌리면 보이는 창은 1848 × 2448 → 위쪽(세로판)
- 가로일 때 보이는 창은 1848 × 1395 → 아래쪽(가로판)
- 확대·축소 없이 **끌어 옮기기만으로** 한 장씩 정확히 보입니다. 핀치 제스처를 주입할 필요가 없는 게 핵심입니다.

순서:

1. 갤러리에서 콜라주를 열고 「배경화면으로 설정」 → 「홈 화면」.
2. 편집기가 가로(기본)일 때 아래쪽 판이 보이게 천천히 끌어 올립니다. `adb shell input swipe <x> <y1> <x> <y2> 1500` 처럼 **느리게, 여러 번 나눠서**.
3. 편집기를 연 채로 화면을 세로로 돌립니다. 폰을 돌리지 않아도 `adb shell settings put system user_rotation 1` 로 돌아갑니다.
4. 이번엔 위쪽 판이 보이게 끌어 내립니다.
5. 완료 → `user_rotation 0` 으로 되돌리고, 두 방향 홈 화면을 캡처해 확인합니다.

## 3. 세로 영상을 4:3 잠금화면용으로 넓히기

세로 영상을 펼친 화면(4:3 가로)에 그대로 넣으면 위아래가 잘려 높이의 45% 정도만 보입니다. 영상은 가로·세로 크롭을 따로 줄 수도 없습니다.

1. 영상에서 **움직임이 적은 프레임** 하나를 뽑아 4:3 캔버스 가운데에 높이를 맞춰 놓습니다.
2. 양옆만 비운 마스크로 인페인팅합니다(「양옆엔 벽·바닥 같은 배경만, 인물이나 효과는 그리지 말 것」).
3. ffmpeg로 넓힌 정지 배경 위에 원본 영상을 가운데 겹치고, 좌우 경계를 170~190px 폭으로 부드럽게 섞습니다.

```bash
ffmpeg -nostdin -loop 1 -framerate 24 -t 3.05 -i bg.png -i src.mp4 -loop 1 -framerate 24 -t 3.05 -i mask.png \
  -filter_complex "[1:v]scale=736:1232,format=rgba[v];[2:v]format=gray[m];[v][m]alphamerge[vm];[0:v][vm]overlay=448:0:shortest=1,format=yuv420p" \
  -an -c:v libx264 -crf 18 -movflags +faststart out43.mp4
```

- `-loop 1` 입력에 `-t` 를 안 주면 `alphamerge` 가 끝나지 않아 ffmpeg가 영원히 돕니다(`shortest=1` 은 overlay에만 걸립니다).
- 섞는 폭 70px에서는 경계가 보였고 190px에서 사라졌습니다. 위쪽까지 흐리게 섞으면 영상 속 빛줄기가 잘린 것처럼 보여서 좌우만 섞었습니다.

## 4. 충전하면 잠금화면이 영상으로 — 모드 및 루틴

설정 → 모드 및 루틴 → 루틴 → 추가

- **조건**: 충전 상태(충전 중 · 유선 · 무선)
- **동작**: 배경화면 → 「잠금화면 배경 변경 (커버 화면)」과 「(메인 화면)」에 각각 영상 선택
- **루틴이 끝날 때**: 기본값 「루틴 실행 전 설정으로 돌아감」 → 충전기를 빼면 원래 잠금화면으로 돌아가야 합니다.

충전 중에 저장하면 바로 실행되므로, 화면을 껐다 켜서 잠금화면을 캡처해 확인합니다. 다만 **충전기를 뺐을 때 메인 화면 잠금화면이 되돌아오는지는 아직 확인하지 못했습니다.**

## 조용히 빗나가는 함정 8가지

1. **메인(펼친) 화면용 설정은 펼친 상태에서만 됩니다.** 커버에서 루틴의 「잠금화면 배경 변경 (메인 화면)」은 회색으로 비활성이고, 배경 편집기도 지금 켜진 화면만 편집합니다. 이 단계는 사람이 폰을 펼쳐 줘야 합니다.
2. **편집기의 끌기는 그림 경계를 넘어갑니다.** 빠르게 끌면 관성으로 더 가서 그림 밖 흐린 여백까지 보입니다. 느린 swipe를 여러 번 하고, 매번 캡처를 잘라 가장자리를 눈으로 확인합니다. 「swipe를 보냈다」는 증거가 아닙니다.
3. **회전 편집은 자동 회전이 꺼져 있어도 `user_rotation` 으로 됩니다.** 대신 실제로 폰을 돌려서 배경이 바뀌게 하려면 자동 회전(`accelerometer_rotation 1`)을 켜 둬야 합니다.
4. **세로 영상은 펼친 화면에서 잘립니다.** 위 3번처럼 4:3판을 따로 만듭니다.
5. **영상은 갤러리에서 바로 배경으로 못 넣습니다.** mp4를 여는 인텐트는 동영상 플레이어로 가고, 거기엔 「배경화면으로 설정」이 없습니다. 설정 → 배경화면 및 스타일 → 잠금화면 → 배경화면 → 갤러리의 「동영상」 탭에서 고릅니다. 목록이 촬영일 순이라 넣은 파일 위치가 들쭉날쭉하니, 고른 뒤 파일 이름으로 맞는지 확인합니다.
6. **`android.settings.WALLPAPER_SETTINGS` 는 삼성 경로가 아닙니다.** 안드로이드 기본 선택기가 뜹니다.
7. **탭 직후 화면을 읽으면 이전 화면이 잡힙니다.** 탭하고 1.5~3초 기다린 뒤 `uiautomator dump` 를 다시 하고, 못 찾으면 한 번 더 합니다.
8. **작업 중 화면이 꺼지면 잠금이 걸려 adb로 못 풉니다.** 시작 전에 원래 값을 적어 두고 `adb shell svc power stayon ac` 로 켜 두었다가, 끝나면 되돌립니다.

그 밖에: 백그라운드로 넘어간 ffmpeg를 끈 뒤에는 **새 파일 이름**으로 다시 출력합니다. 같은 파일에 남은 쓰기가 겹치면 `Invalid NAL unit size` 로 영상이 깨집니다.
